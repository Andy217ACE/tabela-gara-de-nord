# Historical planning documents

The files in `plans/`, `specs/` and `analysis/` are working documents from the time the features were
planned. They are **historical**: they describe intentions at that moment, may mention hosts (such as
Azure) or numbers that are no longer true, and are not kept up to date. The current state is described
by `README.md` and the pages in `docs/` (see `docs/api.md`, `docs/deploy-si-configurare.md`,
`docs/decizii-arhitectura.md`).
