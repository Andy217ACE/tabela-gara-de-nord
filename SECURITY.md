# Politica de securitate / Security policy

## Română

**Raportare:** nu deschide un issue public. Folosește *Report a vulnerability* din fila **Security** a acestui depozit GitHub (raportare privată). Răspund cât pot de repede.

**Domeniu:** aplicația (`app/`, `web/`) și fișierele de instalare/operare din `deploy/`. În afara domeniului: serverul CFR, serviciile terțe, instalările modificate de terți.

**Versiuni suportate:** doar cea mai recentă versiune Beta (vezi `VERSION`).

**Cheia de administrare:** dacă bănuiești că tokenul de admin a ieșit public, rotește-l conform `docs/admin-rotatie-cheie.md`.

Nu include secrete reale sau date personale în raport.

## English

**Reporting:** do not open a public issue. Use *Report a vulnerability* in the repository's **Security** tab (private reporting). I will respond as soon as I can.

**Scope:** the app (`app/`, `web/`) and the install/operations files in `deploy/`. Out of scope: the CFR server, third-party services, installations modified by others.

**Supported versions:** only the latest Beta release (see `VERSION`).

**Admin token:** if you suspect the admin token leaked, rotate it as described in `docs/admin-rotatie-cheie.md`.

Do not include real secrets or personal data in a report.
